# YAMP

Пакет __YAMP__ (Yet Another Message Processor) предназначен для классификации, разбора и форматирования текстовых
сообщений. Пакет реализован на языке Python.

**Описание базовых понятий** 
- Входное сообщение (In message) - текстовое сообщение, которое классифицируется, разбирается и форматируется;
- Шаблон (Template) - описание свойств и структуры Входного сообщения;
- Запись шаблона (Template record) - описание повторяющихся фрагментов Входного сообщения;  
- Поле шаблона (Template field) - описание элемента Входного сообщения;
- Структура (Structure) - результат разбора Входного сообщения по Шаблону; 
- Модель (Model) - описание свойств и структуры Выходного сообщения;
- Предопределенное поле (Predefined field) - поле с вычисляемым системой значениями; 
- Пользовательские поля (Custom field) - определенное пользователем поле.


Пакет конфигурируется настройками, выгруженными в файлы из базы данных AirCom в каталог db:
1. В подкаталоге __models__ находятся файлы, описывающие модели: 
   -  расширение __.json__ - описание модели; 
   - расширение __.txt__ - текст модели в формате AirCom;
   - расширение __.jinja__ - текст модели в формате Aeron.
2. В подкаталоге __settings__ находятся файлы с дополнительными данными.
   - aircraft_fleets.json - справочник ВС;
   - aircraft_types.json - справочник типов ВС;
   - data_formats.json - форматы полей;
   - field_types.json - типы полей;
   - lookup_tables.json - таблицы подстановок;
   - lookup_items.json - элементы подстановок;
   - predefined_fields.json - предопределенные поля;
   - custom_fields.json - пользовательские поля;
   - substring_replace.json - значения для замены в полях моделей. 
3. В подкаталоге __templates__ находятся файлы, описывающие шаблоны.

Путь к каталогу db передается в каждый класс пакета при инициализации.

```
discriminator = yamp.discriminator(db_directory_path='db') 
parser = yamp.parser(db_directory_path='db')
modeller = yamp.modeller(db_directory_path='db')
```
   
Внешние зависимости и пакеты Python:

- __dms2dec__>=0.1;
- __jsonschema__>=4.23.0;
- __jinja2__>=3.1.4.

### Описание файлов

| Файл                | Описание                         |
|---------------------|----------------------------------|
| __\_\_init\_\_.py__ | файл пакета;                     |
| __yamp.py__         | основной "движок" работы пакета; |
| __models.py__       | описание классов;                |
| __exceptions.py__   | описание исключений;             |
| __settings.py__     | настройки пакета;                |
| __utils.py__        | вспомогательные функции;         |
| __handlers.py__     | реализация бизнес-логики;        |
| __template.json__   | JSON схема для шаблонов;         |
| __model.json__      | JSON схема для моделей.          |


1. ### __yamp.py__
      Файл содержит классы обработки входных сообщений: __discriminator__, __parser__, __modeller__.
   
      #### Класс discriminator
      
      Класс предназначен для сопоставления шаблонов входным сообщениям.
      
      Дискриминатор проверяет файлы шаблонов на уникальность идентификаторов, уникальность идентифицирующих
      полей (SMI, SubSMI1, SubSMI2, SubSMI3, LongRegistration, AircraftTypes) и на наличие в каталоге ровно __одного__
      шаблона по умолчанию. __Шаблон по умолчанию__ - это шаблон, к которому относиться сообщение, если не найдено ни
      одного подходящего шаблона. Данный шаблон имеет __SMI=null__ и __Specificity=-1__.
      
      __Примечание__: если сообщение отнесено к шаблону по умолчанию,
      то в его структуру помещаются только значения полей SMI, Long Registration и Aircraft type.
<br/><br/>
      ```discriminator = yamp.discriminator(db_directory_path='db')```
<br/><br/>
      Класс discriminator имеет один публичный метод ___identify_template___. 
<br/><br/>**Метод identify_template**

    Сопоставляет входному сообщению шаблон. Метод принимает параметр: __path_file_message__ - либо строку со входным сообщением, либо путь до файла с входным сообщением.
      
      Для входного сообщения определяется шаблон с наибольшим совпадением значений идентифицирующих полей. 
      Если для сообщения по значениям идентифицирующих полей не подошел ни один шаблон, то для сообщения 
      определяется шаблон по умолчанию.
      
      Возвращаемое значение: __DescriptorResult__.
   <br/><br/> 

   ```discriminator_result = discriminator.identify_template(path_file_message=message)```
    <br/><br/>
      **Исключения**
      
      - _ValueError_ - если переданный параметр __db_directory_path__ не является путем к каталогу;
      - _ValidateTemplateToSchemaException_;
      - _ValidateModelToSchemaException_;
      - _DuplicateDefaultTemplateException_;
      - _DuplicateTemplateException_;
      - _DuplicateTemplateIdException_.
      
      #### Класс parser
      
      Класс предназначен для разбора входных сообщений в структуры по шаблонам.
      
      Класс parser имеет один публичный метод ___parse___.
<br/><br/>
      **Метод parse**
      
      Параметры: __data__ - строка со входным сообщением или путь до файла с входным сообщением; 
      __template__ - экземпляр класса TemplateInfo или путь до файла шаблона.
      
      Возвращаемое значение: ___ParserResult___. 
      
      **Пример структуры:**

      ```json
   {
          "SMI": {
              "original": "DFD",
              "internal": "DFD"
          },
          "Flight Information": [
              {
                  "Flight Information.UTC": {
                      "original": "153039",
                      "internal": 153039.0
                  },
                  "Flight Information.City first identification": {
                      "original": "URML",
                      "internal": "URML",
                      "converted": "KAZAN"
                  }
              }
         ],
         "CE": [
              {
                  "CE.Total Air Temperature": {
                      "original": "-365",
                      "internal": -365.0
                  },
                  "CE.Standard Altitude": {
                      "original": "34007",
                      "internal": "34007"
                  }
              }
         ]
   }
   ```

      ```python
      template = TemplateInfo(load_json("21.json"))
      parser_result = parser.parse('test/21.txt', template)
      ```
      
      #### Класс modeller
      
      Класс предназначен для формирования выходных сообщений из структур по моделям.
      
      Класс modeller имеет один публичный метод ___reformat___.
      
      Выходное сообщение формируется шаблонизатором [__jinja2__](https://pypi.org/project/Jinja2/).
      <br/><br/>
      **Метод reformat**
      
      Параметры: __structure__ - структура, __model__ - модель в формате ModelInfo, по которой будет
      происходить преобразование.
      
      Возвращаемое значение: ___ModellerResult___.
      <br/><br/>
    Данный метод реализует преобразование структуры в выходное текстовое сообщение согласно заданной модели.
      В методе используется шаблонизатор jinja, который преобразует файл .jinja в текст.
      
      ```python
      modeller_result = modeller.reformat(parser_results.original_structure, model)
      ```

2. ### __settings.py__
      Файл содержит два словаря __SMI__ и __LONG_REGISTRATION__. Они являются стандартными правилами выделения значений
      SMI (system mesage identifier)
      и регистрационных номеров ВС из сообщений.
   
      акже файл содержит константы, определяющие типы полей, пути до JSON-схем шаблонов и моделей, форматы дат, а также пути до других файлов настроек.
3. ### __models.py__
      Файл содержит классы для работы с шаблонами и моделями.
   - ___TemplateBase___ - абстрактный класс, который является родительским для остальных классов;
   - ___TemplateInfo___ - класс, описывающий шаблон (таблица __Template__ за исключением __MsgExample__);
   - ___TemplateRecord___ - класс, описывающий запись шаблона (таблица __TemplateRecord__); 
   - ___TemplateField___ - класс, описывающий поле шаблона (таблица __TemplateField__);
   - __ModelInfo__ - класс, описывающий модель (таблица __Model__);
   - __ModelField__ - класс, описывающий поле модели (таблица __ModelField__);
   - ___DescriptorResult___ - класс для результата работы дискриминатора (yamp.discriminator).
      
     Содержит атрибуты:
       - code - код результата: 
         - __0__ - успешное определение шаблона;
         - __-3__ - ошибка разбора входного сообщения;
         - __-5__ - ошибка поиска ВС в справочнике;
         - __-7__ - другие ошибки.
       - dsg - подробное сообщение результата;
       - template - шаблон (формат TemplateInfo);
       - id_template - идентификатор шаблона.
   - ___ParserResult___ - класс для результата работы парсера. 
   
      Содержит атрибуты:
      - code - код результата:
        - __0__ - успешный разбор входного сообщения;
        - __-1__ - шаблон не соответствует JSON-схеме;
        - __-2__ - входное сообщение не подходит под указанный шаблон;
        - __-3__ - ошибка разбора входного сообщения;
        - __-4__ - ошибочное значение;
        - __-5__ - ошибка поиска ВС в справочнике;
        - __-6__ - числовое значение вне допустимого диапазона;
        - __-7__ - другие ошибки.
      - dsc - подробное сообщение результата;
      - structure - словарь со структурой разбора в исходном виде;
  
   - ___ModellerResult___ - класс для результата работы моделлера (yamp.modeller).
        
      Содержит атрибуты:

       - code - код результата:  
         - __0__ - успешное завершение работы;
         - __-3__ - неизвестное поле в модели;
         - __-4__ - ошибка формата поля;
         - __-7__ - остальные ошибки.
       - dsg - подробное сообщение результата;
       - message - выходное сообщение.

4. ### __exceptions.py__
   Исключения, которые возникают в ходе работы пакета.

    - ___NotStartIdInMessageParsingException___ - указанный в шаблоне символ начала поля, начала записи или
      начала поля записи не найден при разборе поля в текстовом сообщении (ошибка разбора);
    - ___NotEndIdInMessageParsingException___ - указанный в шаблоне символ конца поля или конца записи не
      найден при разборе поля в текстовом сообщении (ошибка разбора);
    - ___NotFoundDelimiterParsingException___ - указанный в шаблоне символ разделителя не найден при разборе поля или
      записи в текстовом сообщении (ошибка разбора);
    - ___NotMandatoryFieldParsingException___ - не найдено обязательно поле в сообщении (ошибка разбора);
    - ___NotFindLeastOneRecordParsingException___ - при разборе текстового сообщения не удалось найти ни одного поля записи (ошибка разбора);
    - ___BadLengthParsingException___ - указанная в шаблоне длина поля больше чем размер текстового сообщения (ошибка разбора);
    - ___DateFieldFormatException___ - в сообщении указана дата в неверном формате (ошибка формата);
    - ___CoordinateFieldFormatException___ - в сообщении указана координата в неверном формате (ошибка формата);
    - ___NumericFieldFormatException___ - в сообщении указано метрическое поле в неверном формате (ошибка формата);
    - ___AlphanumericFieldFormatException___ - в сообщении символьно-числовое поле в неверном формате (ошибка формата);
    - ___BooleanFieldFormatException___ - в сообщении указано бинарное поле в неверном формате (ошибка формата);
    - ___OutOfRangeHighException___ - выход за пределы ограничений, числовое поле уходит
      за пределы верхнего значения (ошибка значения);
    - ___OutOfRangeLowException___ - выход за пределы ограничений, числовое поле уходит
      за пределы нижнего значения (ошибка значения);
    - ___UnknownAircraftException___ - не найден регистрационный номер самолёта в справочнике ВС;
    - ___TemplateDuplicateException___ - шаблон дублируется;
    - ___ValidateTemplateToSchemaException___ - шаблон не соответствует JSON схеме;
    - ___ValidateModelToSchemaException___ - модель не соответствует JSON схеме;
    - ___DuplicateDefaultTemplateException___ - дублируется шаблон по умолчанию, в каталоге с шаблонами присутствуют
      несколько шаблонов с __SMI=null__ и __Specificity=-1__.
    - ___DuplicateTemplateIdException___ - дублируется идентификатор шаблона;
    - ___NotFoundDefaultTemplateException___ - в папке с шаблонами не найден шаблон по умолчанию (поле Specificity=-1 и
      SMI=null);
    - ___NotFileException___ - не найден указанный файл;
    - ___NotFoundSMIException___ - в сообщении не найден SMI;
    - ___NotFoundLongRegistrationException___ - в сообщении не найден Long Registration;
    - ___UnknownDynamicFieldException___ - неизвестное предопределенное ил пользовательское поле;
    - ___UnknownTemplateFieldException___ - неизвестное поле разобранной структуры;
    - ___FormatDateTimeModelException___ - неправильный формат даты\времени у поля;
    - ___FormatNumericModelException___ - неправильный формат числа.


### Релиз

Вкладка __"Release"__ - содержит релизы пакета YAMP. 

Для установки пакета необходимо скачать пакет __yamp__ и в командной строке выполнить команду:
```commandline
pip install yamp.tar.gz
```

После этот пакет YAMP установиться в окружение вашего интерпретатора python и его можно использовать в коде.


```python
import yamp
```
